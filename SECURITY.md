# Security Policy

DataForge executes SQL and dbt code generated by an LLM. Please report any way to escape the sandbox, read credentials, reach the network from the sandbox worker, or write to the serving warehouse without an approved version.

## Reporting a vulnerability

Do not open a public issue. Use GitHub private vulnerability reporting on this repository ("Security" tab, "Report a vulnerability"). Include the affected component, steps to reproduce and the impact.

## Scope

In scope: `backend/worker/sandbox.py`, `backend/app/codegen/guard.py`, the Compose network and container settings, credential handling, approval fingerprints.

Out of scope: vulnerabilities in pinned third-party images or packages with no DataForge-specific exploit path; report those upstream.
